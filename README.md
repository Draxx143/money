# صفحهٔ نیلی — Indigo Screen

یک برنامهٔ ساده برای دسکتاپ اوبونتو: فقط یک صفحهٔ تمام‌صفحهٔ نیلی (`#4B0082`)، بدون متن، دکمه یا نوار عنوان. نشانگر ماوس نیز داخل پنجره پنهان می‌شود. برای خروج **Esc** را بزنید؛ **Alt+F4** هم کار می‌کند.

## نصب روی اوبونتو

فایل `indigo-screen_1.0.0_all.deb` را دانلود کنید و در پوشهٔ دانلودشده اجرا کنید:

```sh
sudo apt install ./indigo-screen_1.0.0_all.deb
```

سپس از فهرست برنامه‌ها **Indigo Screen / صفحهٔ نیلی** را باز کنید یا دستور زیر را اجرا کنید:

```sh
indigo-screen
```

این بسته به محیط دسکتاپ و Python 3، PyGObject و GTK 3 نیاز دارد. دستور `apt install` وابستگی‌های لازم را از مخازن اوبونتو نصب می‌کند. بسته مستقل از معماری است و برای دسکتاپ‌های Ubuntu دارای GTK 3 تهیه شده است؛ روی محیط بدون نمایشگر اجرا نمی‌شود.

## ساخت بسته

با وجود `dpkg-deb` در سیستم:

```sh
sh scripts/build-deb.sh
```

خروجی: `dist/indigo-screen_1.0.0_all.deb`

## حذف

```sh
sudo apt remove indigo-screen
```
